# Apply This Update

1. Back up the current project folder.
2. Extract this ZIP into the existing project root and allow it to overwrite matching files.
3. Add the Hostinger SMTP environment variables shown in `HOSTINGER_EMAIL_SETUP.md` to Vercel or your Node.js hosting panel.
4. Run:

```bash
npm install
npm run build
```

5. Redeploy and submit one test project enquiry.

No additional npm package was added by this update.
